# Talkie - Real-Time Chat Application

A full-stack real-time messaging application built with modern web technologies. Talkie enables users to communicate instantly with features such as real-time messaging, online presence tracking, image sharing, notifications, and secure authentication.

The project focuses on implementing real-world communication systems using WebSockets, REST APIs, authentication, cloud services, and scalable backend architecture.

---

## Features

### 🔐 Secure Authentication
- Custom JWT-based authentication system
- No third-party authentication providers used
- Secure cookie-based session management
- Protected API routes

### ⚡ Real-Time Messaging
- Instant messaging using Socket.io
- Real-time message delivery
- Online/offline user presence indicators
- Live communication between connected users

### 🔔 User Experience Features
- Typing indicators
- Message notification sounds
- Sound toggle preferences
- Welcome emails after account creation

### 🖼️ Media Sharing
- Image upload functionality
- Cloud-based image storage using Cloudinary

### 🛠️ Backend Features
- RESTful API architecture
- Node.js and Express backend
- MongoDB database integration
- Mongoose for database modeling
- API rate limiting with Arcjet

### 🎨 Frontend Features
- Responsive user interface
- React-based frontend
- Tailwind CSS styling
- DaisyUI components
- Zustand state management
